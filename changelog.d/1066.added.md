Added a `momentum` subcommand: re-scores the saved report cache under a shorter lookback window (default 7 days) and diffs the two rankings — offline, no re-search, no additional API calls. Classifies candidates as breakout / fading / sustained by rank movement, reports the short-window share of total engagement, and renders a momentum brief (or `--emit=json`). Any window pair works via `--days` and `--as-of` (90→30, 14→3); scoring reuses the engine's own functions so both windows compute identically except for the freshness scale and window membership.
