The Grok X lane now escapes the search topic into a single-line JSON string literal inside the `grok -p` prompt, so quotes, backslashes, newlines, and invisible or line-breaking Unicode in a topic can no longer break the prompt's framing. The permission-bypassed `grok` child also runs with every non-X built-in tool removed (shell, command monitor, workflows, file read/write/edit, grep, directory listing, web search and fetch, subagents, MCP bridge, and media generation). The model still reads the topic to build its X query, so a topic carrying instructions can at most steer which X searches run and what the model reports from them.
