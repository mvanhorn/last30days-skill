YouTube availability is now canonical and SSH-aware, and explicitly requested unavailable sources are reported as typed skips instead of being silently dropped or substituted. `youtube_yt.ytdlp_route()` is the single predicate answering availability for the planner, pipeline gates, `--diagnose`, and execution: it distinguishes `local` (persistent PATH binary, never a `/tmp`/`/var/tmp` target), `ssh` (`LAST30DAYS_YOUTUBE_SSH_HOST` + local `ssh`), and `unavailable` (including dangling or off-PATH binaries), so a source is never advertised available when its exact execution route cannot run. `--diagnose` now reports the route under `ytdlp_route`. External plans preserve every explicitly requested unavailable source as a typed `skipped-unconfigured` result with a safe detail; a subquery whose every explicit source is unconfigured is dropped rather than rewritten to unrelated eligible sources, and a run whose every requested source is unconfigured returns an honest empty report instead of raising. Generic eligibility fallback for plans that did not constrain sources is unchanged.
