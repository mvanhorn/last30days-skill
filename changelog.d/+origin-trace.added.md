**Patient Zero: trace where a story started and how it spread.** Ask where a story, meme, or claim started and the report gains a Spread Timeline: the earliest post found, each platform's first sighting in date order with the gap between them, the peak day, and the single biggest post. It reports "earliest found" as a lower bound and lists what limits the trace (a trail that runs past the search window, sources that did not report cleanly, undated posts). New `--trace-origin` engine flag for single-topic compact and Markdown runs.
