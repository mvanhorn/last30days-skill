- Serialized SQLite usage journal writes with a process-level lock, WAL mode, `BEGIN IMMEDIATE`, and 30-second busy timeouts, and guarded `usage.begin()`/`cancel()`/`finish()` against `sqlite3.Error` so journal failures never abort live HTTP calls or mask transport errors.
- Stripped unsubstituted `${user_config.*}` placeholders per configuration layer in `lib/env.py` before secret-store fallback, layer merging, alias resolution, lazy env exports, and browser-cookie preflight calculation, while preserving `None` vs `""` semantics and process-env-only boundaries.
- Clamped `http.request(..., retries=...)` to at least 1 attempt so callers passing `retries=0` (including Bluesky session refresh and Xquik key probes) execute one attempt instead of failing immediately with zero attempts.
- Switched watchlist Slack and generic webhook delivery to `http.post_raw()` so plain-text 2xx responses (such as Slack's `"ok"`) succeed instead of failing JSON parsing with `schema_drift`.
- Validated `daily_budget` in `watchlist.py config budget` and shared a fail-closed `_parse_budget()` parser across `watchlist.py` and `briefing.py` to reject `NaN`, `inf`, negative, and non-numeric values.
- Made `store.store_findings()` atomic with `BEGIN IMMEDIATE` and unconditional `ON CONFLICT(source_url) DO UPDATE` plus in-transaction sighting ID resolution so concurrent topic or finding deletions cannot cause stale-ID foreign-key failures or drop batches.
- Closed all SQLite connections unconditionally in `lib/library_index.py` via a managed context helper, preventing file descriptor leaks and ensuring corrupt database rebuilds close handles before unlinking files.
