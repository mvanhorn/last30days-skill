Add Kagi Search API as an opt-in web search backend: set `KAGI_API_KEY` to route web search through `kagi.com/api/v0/search`. Kagi sits at the end of the paid-backend auto-detection chain (after Brave / Exa / Serper / Parallel) and can also be selected explicitly with `--web-backend=kagi`. Documented in CONFIGURATION.md; 6 unit tests in `test_grounding_v3.py`.
