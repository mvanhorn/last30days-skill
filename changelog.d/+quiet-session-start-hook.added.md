`LAST30DAYS_QUIET` quiets the SessionStart status hook. Setting it to a truthy value (`1`, `true`, `yes`, `on`) drops the first-run welcome and the ScrapeCreators tip while keeping the one-line status and the last-run summary. Previously there was no way to turn either off: an install that deliberately stays on the free sources was advised to run the setup wizard at every session start, in every project, indefinitely. The variable resolves through the existing precedence chain (process environment, then the global `.env`, then a trusted project file), and is a no-op when unset or falsy.
