Perplexity synthesis now runs on the Agent API (`/v1/agent`) instead of Sonar chat completions. Sonar model names stay as the config surface and map to Agent API presets (`sonar`→`fast`, `sonar-pro`→`low`, `sonar-reasoning-pro`→`medium`, `sonar-deep-research`→`high`), with `LAST30DAYS_PERPLEXITY_PRESET` available to pick a preset directly (including `xhigh`). Deep Research uses background runs and measured ~$0.32/query against ~$0.90 on Sonar Deep Research; artifacts now carry `preset`, the model the preset actually selected, and the API-reported `totalCostUsd`. Date, domain, and recency filters move onto the `web_search` tool and were verified to still bound results. `LAST30DAYS_PERPLEXITY_SEARCH_MODE` and `LAST30DAYS_PERPLEXITY_LANGUAGE_FILTER` have no Agent API equivalent and are now logged and ignored. The OpenRouter fallback is unchanged and still speaks Sonar.
