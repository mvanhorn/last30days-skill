X search now discovers browser cookies for Bird from more places: the `agentcookie` sidecar CLI (set `AGENTCOOKIE=off` to disable; independent of `FROM_BROWSER`) and a live signed-in Chrome/Chromium session over the DevTools Protocol (scanned on localhost debug ports; `FROM_BROWSER=off` skips it), in addition to the existing browser-cookie extractor. The engine takes the first complete `auth_token`+`ct0` pair and never writes cookies to disk. The unpinned X backend chain is now bird → grok → xai → xurl → xquik, with the Grok CLI promoted to a fail-closed backup after Bird: it is auto-selected only when signed in with a valid session, so a leftover or expired `~/.grok/auth.json` never steals first place over Bird and never blocks the fall-through to xAI.
