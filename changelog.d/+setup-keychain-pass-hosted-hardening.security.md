Hardened hosted API client, GitHub device-auth setup wizard, and Keychain/pass helper scripts:
- Bypass ambient `HTTP_PROXY` for loopback `http://` `LAST30DAYS_API_BASE` requests, block cross-origin redirects, reject embedded URL userinfo/query/fragment/backslashes/invalid ports and control characters in `LAST30DAYS_API_BASE` and `LAST30DAYS_API_KEY`, and scrub credentials from hosted error output.
- Strictly validate GitHub device-auth `verification_uri` values (exact HTTPS `github.com` under `/login/device`, no query/fragment/userinfo/control characters) before emitting or launching `webbrowser.open()`.
- Route device-auth HTTP requests in `setup_wizard.py` through a dedicated HTTPS-only no-redirect opener (bypassing any wrapped `urllib.request.urlopen`), bound response sizes, close `HTTPError` streams, and redact secrets from HTTP error details before logging or returning them.
- Pin `/usr/bin/security` unconditionally when present and pass hex-encoded secrets over stdin via `security -i` in `setup-keychain.sh` instead of passing plaintext secrets on process `argv`.
- Validate `LAST30DAYS_PASS_PREFIX` and key names against `ALL_KEYS` (with Bash 3.2–safe regexes), and pass `--` end-of-options markers to every `pass` invocation in `setup-pass.sh`.
