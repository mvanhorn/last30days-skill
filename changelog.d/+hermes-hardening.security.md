Setup no longer downloads or runs third-party code. It never runs `npx`, `npm`, `curl | sh`, or `git clone`. The only automatic install is `brew install yt-dlp`. arXiv and Techmeme are now built-in stdlib clients. The optional Digg CLI is detected only; if it's missing, setup prints `scripts/build-pp-cli.sh digg`, which builds it from a pinned, reviewed fork commit when you run it yourself.
