Entity-miss demotion no longer goes inert on topics without a distinctive named entity. `_primary_entity` stripped intent modifiers anywhere in the topic, so "AI code review bottleneck" lost "review", and `_entity_grounded` keyed on a head token so generic ("AI") that every item in an AI-adjacent corpus grounded. Modifiers are now stripped only as a trailing suffix, and grounding falls through to a more discriminating token when the head token is too short or common to be evidence.
