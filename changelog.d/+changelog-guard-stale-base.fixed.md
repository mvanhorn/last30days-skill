The changelog guard now resolves a pull request's base with `git merge-base` at job time instead of `github.event.pull_request.base.sha`, which is fixed when the PR is created and never refreshed as the base branch advances. A PR whose base moved forward is no longer graded against a commit that is not its base, so the guard stops reporting `CHANGELOG.md` edits and version bumps that belong to the base rather than the PR.
