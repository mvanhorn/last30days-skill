feat: add V2EX and Xueqiu (雪球) Chinese community sources

- `v2ex` source: always eligible, uses the public V2EX HTTPS API (hot
  topics + default node listings), filters by token-overlap relevance,
  and attaches top replies as enrichment. No API key required.
- `xueqiu` source: Chinese investor sentiment from the v4 public
  timeline, gated to ticker/crypto topics (same `_financial_topic`
  chokepoint as StockTwits) plus a `XUEQIU_COOKIE` config requirement.
  Includes hot-stock context as a secondary candidate stream.
- Both sources follow the existing listing-adapter pattern: normalize to
  the shared web-item shape, hard date filter, relevance gate, and
  engagement in `SourceItem.engagement`.
- `available_sources()` registers `v2ex` unconditionally and `xueqiu`
  only when the financial gate and cookie both hold, so the planner can
  never assign Xueqiu to a non-financial topic.
- Tests: `tests/test_v2ex.py`, `tests/test_xueqiu.py` (pure-logic unit
  tests; network calls mocked). `KNOWN_SOURCE_NAMES` updated.
