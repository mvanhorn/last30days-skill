`setup-keychain.sh` no longer passes a credential on the `security` command line, where it was visible in `ps` output to every user on the machine for the duration of the call; the value is piped to `-w` on stdin instead (the form `man security` recommends). Presence checks also stop requesting plaintext with `find-generic-password -w`, so storing or listing keys no longer decrypts a secret the script has no use for. Two static drift guards in `tests/test_env_keychain.py` fail the suite if either pattern returns.
