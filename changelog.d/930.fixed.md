`.env` values no longer keep their inline `# comment`. Copy-pasting CONFIGURATION.md's own documented examples silently corrupted settings — `LAST30DAYS_MEMORY_DIR` resolved to a directory whose name contained the comment, and `BSKY_SEARCH_HOST` produced an unresolvable URL. A `#` preceded by whitespace now starts a comment (matching the session-start hook's parser), while a `#` glued to the value or inside quotes stays data. `export KEY=value` lines are also honored instead of parsing as a key literally named `export KEY`.
