Job postings now reach the report as a `## Jobs Digest` evidence section in place of the opening lines of each description: up to 40 of the board's rarest roles, each with the text no other role on that board repeats. The footer Jobs line reads `N open roles`, adds `M new in the L30` only when the board gives every role a true first-posted date (Greenhouse now uses `first_published`, not `updated_at`), and shows `2,000+` for a board that was capped or cut short. Workday descriptions are fetched for the digest's roles only. The MCP `research` tool returns the footer line without the digest.
