Hardened CLI privacy, read-only, and concurrency boundaries: `--record-fixtures` now refuses logged-in Reddit sessions during `--drill` and `--discover` runs; `--mock`, `--discover --finalize`, hosted API runs, empty/invalid invocations, and non-auto `setup` sub-flags no longer trigger browser cookie reads; `--preflight` and `--diagnose` can no longer be bypassed by mutating subcommands (`setup --store-key`, `setup`, `library feed`, `queue cover`); parallel comparison fan-out and `pipeline.run()` now isolate per-entity `config` dicts to eliminate races and state leakage; and cache-only `--verify-freshness` now enforces `--publish-html` requires `--emit=html` and honors `--synthesis-file`.
