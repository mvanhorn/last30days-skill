Runtime preflight and version-badge snippet no longer break when the topic has two or more words. Claude Code substitutes `$1`, `$2`, … in a SKILL.md body with the skill's argument words before the model reads it, so the preflight's `"$1"` reached the model as a literal topic word and every interpreter candidate was tested against it. The shell positional references are now braced (`${1}`) and the awk version field is now `$(2)`, which read identically to their interpreters and survive substitution.
