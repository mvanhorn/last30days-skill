TikTok works without a ScrapeCreators key, and Instagram works on a best-effort basis. When the key is missing or ScrapeCreators returns HTTP 402, both sources find public post URLs and read each post with `yt-dlp`, logged out. Post URLs come from a self-hosted SearXNG (`LAST30DAYS_SEARXNG_URL`), Serper, Exa (TikTok only), Brave or the keyless floor, and on hosts with their own web search from the new `--shortform-urls` envelope, which the runbook fills from 2-3 `site:tiktok.com` / `site:instagram.com` searches. Discovery asks each backend for recent results (`LAST30DAYS_SHORTFORM_FRESHNESS`), and TikTok also lists the recent on-topic videos of creators seen in discovery (`LAST30DAYS_SHORTFORM_CREATOR_EXPANSION`). Every post is dated from its id before any fetch and again after extraction, so the lane never keeps a post from outside the research window: a thin month returns zero with the reason. Instagram recall is low (public pages, no view counts), and comments on both platforms stay ScrapeCreators-only, so the key is still the better path. `doctor` names the discovery sources armed for each platform and calls Instagram best effort. `APIFY_API_TOKEN` is no longer treated as a TikTok search credential (it was never wired to an Apify actor).
