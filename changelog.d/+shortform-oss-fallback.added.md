TikTok and Instagram no longer require a ScrapeCreators key to run. When the key is missing or returns HTTP 402, both sources fall back to web discovery (self-hosted SearXNG via `LAST30DAYS_SEARXNG_URL`, Serper, Exa, Brave, or the keyless floor) followed by `yt-dlp` per-post metadata extraction — the same binary the YouTube source already uses. Discovery queries avoid `site:` filters (Serper's free tier rejects them) and date filtering happens after extraction, not at the search engine. `doctor` reports the fallback as an armed backup lane and stops prescribing a ScrapeCreators key it does not need; `APIFY_API_TOKEN` is no longer treated as a TikTok search credential (legacy alias only; it was never wired to an Apify actor).
